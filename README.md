# 🏦 Bank System

A console-based bank management system written in C++ using object-oriented programming.

## ✨ Features

- Three user roles: Admin, Employee and Client
- Client and employee management (add, edit, list, search)
- Account operations: deposit, withdraw, transfer and balance check
- Data persisted in text files

## 🛠️ Tech Stack

- C++ (OOP: classes, inheritance, file handling)
- Code::Blocks project files included

## 🚀 How to Run

Open the project in Code::Blocks (`Banksystem.cbp`) or compile the `.cpp` sources with any C++ compiler, then run the executable.
